# 收盘后分析使用说明（T006 S3c）

每天收盘（北京时间 15:30 以后）跑一次：对全市场约 5000 只股票算 24 个因子，对比你监控的名单，判断市场状态，给出残差 Z-score 排名，并检查成本会计恒等式。
结果只是**复盘与关注参考**，没有样本外检验、没有扣成本，也不是买卖建议。

## 运行
```
python3 -B scripts/run_eod_analysis.py --day 2026-10-23 --output DIR
```
- 默认读 `data/market_monitor_intraday/<day>.jsonl`（S3b 盘中追踪写的）和 `data/daily/cn_all`（日线 parquet）；默认输出到 `data/market_monitor_intraday/<day>_eod/`。
- 输出目录已有内容就**拒绝覆盖**（退出码 2）；换一个 `--output`。符号链接目录也拒绝。
- 可选：`--jsonl`、`--daily-dir`、`--ledger 账户流水.json`。
- 北京时间 15:30 前，当天的 K 线按"盘中半天数据"丢弃，报 `no_bar_for_day`；日期在未来报 `future_day`。
- 只读本地文件，不联网，不写信号账本。
- **封存段硬守卫**：分析日 ≥ 2026-04-01（`LOCKED_SEGMENT_START`）一律拒绝（`locked_segment`，退出码 1），读日线后也截断到 2026-04-01 之前。锁定段只在最终测试时用。
  注意这意味着目前只能分析 2026-03-31 及以前的日期；分析"今天"需要所有者先明确封存规则（见 handoff/reports/T006_S3c.md 的待决定事项）。

## 输出（三个文件）
| 文件 | 内容 |
|---|---|
| `factor_summary.csv` | 每个因子：有效股票数、触发数、触发率、与大盘相关(近60日)、命中随机60/成交额前60/涨幅前60/监控名单的比例、与监控名单的重合只数 |
| `residual_zscore_rank.csv` | 残差 Z-score 前 k（buy_watch，关注）与后 k（avoid，避开），k = min(20, 合格只数÷2)，两个名单互斥；已过流动性/ST/停牌过滤 |
| `eod_report.md` | 上面的汇总 + 市场状态与建议敞口 + 成本会计恒等式 + 警告 |

怎么读：
- **触发集**：score 因子取方向调整后截面最靠前的 10%；flag 为 True；filter 为通过。
- **与大盘相关**：前一日收盘后确定的触发集，次日等权收益与大盘收益在近 60 日的相关系数（样本 <20 为空）。高相关说明这个因子基本是在赌大盘。
- **命中基准 60**：随机 60 只（固定种子，可复现）、当日成交额前 60、当日涨幅前 60 里有多少比例被这个因子触发；与触发率（base_rate）比较——若命中率约等于触发率，说明因子和该基准没关系。
- **监控重合**：你盯的名单里有几只被该因子触发。

## 市场状态（Regime-Aware）
`identify_regime(大盘水平序列, as_of)`，优先级：数据不足 → unknown；20 日波动率严格高于历史 75 分位 → high_vol；60 日累计 ≥ +5% → trend_up；≤ -5% → trend_down；其余 range。
建议敞口系数：range 100% / trend 60%（上下行相同）/ high_vol 25% / unknown 0%。
局限：5%、75 分位、系数都是约定值，没有调参也没有样本外验证；大盘默认是全市场等权，不是沪深300。

## 残差 Z-score
`get_residual_zscore(个股收益, 大盘收益, 60)`：用不含当天的 60 日窗口估 β，残差 = 个股收益 - β×大盘收益，再用前 60 个残差的均值/标准差标准化。Z 大 = 今天比"按大盘应有的涨幅"多涨得多。
A 股只用多头：前 20 是"关注"，后 20 是"避开"，**不是做空**（T+1、融券受限）。涨幅大 ≠ 之后还涨，Z 高也可能是消息驱动的一次性跳涨；涨停的股票买不到。

## 成本会计恒等式
期末净值 - 期初净值 = 价格盈亏 + 股息盈亏 - 交易费用 - 借券费 - 融资费。A 股借券费/融资费为 0，字段保留。偏差（占期初净值）> 0.1% 在报告和终端里警告：说明漏记了某项成本/分红，或重复计算。
流水 JSON 字段：`start_nav, end_nav, price_pnl, dividend_pnl, trading_fee`（必填，其中 `dividend_pnl` 缺失会报 `missing_dividend`，不会悄悄当 0）、`borrow_fee, financing_fee`（可选，默认 0）；费用按正数传入。没有 `--ledger` 时这一项跳过并在报告里写明。

## 五道验收门槛（数字化，供 T008/T011/T012 引用）
| 门 | 名称 | 通过条件 |
|---|---|---|
| L1 | 数据可信 | 真实股票池 + 含退市股（无幸存者偏差）+ 公司行为（复权/分红/停牌）处理 + 未来函数断言通过 |
| L2 | 真实样本外 | 6 个滚动窗口里 ≥5 个为正；成本翻倍后总体仍为正；Holm 校正后仍显著 |
| L3 | 稳健 | 参数邻域（±20%）内都盈利；月换手 ≤100%；与随机对照的差 >1 个标准差 |
| L4 | 模拟交易 | 纸面 8–12 周；实际滑点在假设的 ±50% 范围内；与回测的偏差月均 <2% |
| L5 | 小规模实盘 | 单票 ≤10%、总仓 ≤80%、日亏损 ≤2%；真实成本与假设相差在 ±30% 内；连续 3 个月跑输大盘 3% 就暂停 |

说明：门是**依次**过的，前一道不过不进下一道；这些数字是项目约定值，不是统计学上的"最优"，事后不得为了通过而放宽。

## 已知局限
- 日线是后复权价：收益率没问题，但 `价格×成交量` 只是成交额近似，"成交额>1亿"和"成交额前60"都不精确。
- 近 60 日相关性、触发集比较是描述性统计，不用来选因子；24 个因子同时看，不做多重检验校正。
- 不扫封存段（有硬守卫）、不做回测收益统计、不写 signal_ledger.db。
