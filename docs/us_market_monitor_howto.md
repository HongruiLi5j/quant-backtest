# 美股盯盘使用说明（T015，仅个人模式）

镜像 A 股盯盘（T006，见 `docs/market_monitor_howto.md`），但数据源换成 yfinance，时段换成美东。**默认关闭**：导入包、打开页面、查询状态都不请求上游，也不启动线程。完整设计见 `docs/us_market_monitor_plan.md`。

## 1. 安装 yfinance
yfinance 不在 requirements.txt 里（可选依赖），要用美股盯盘才装：

    .venv/bin/pip install yfinance

没装时点“开始盯盘”会立刻暂停并显示 `yfinance_not_installed`（这个错误无法自愈，也不消耗请求预算）；装好后再点一次开始即可。
许可证以你本机安装包的 METADATA 为准（设计阶段在本机看到的是 Apache-2.0，不是“MIT”）。yfinance 自述数据仅供个人使用（personal use only），请自行阅读其说明和 Yahoo 的条款。

## 2. 怎么开启
1. 个人模式开启：根目录 `personal_mode.json` 的 `enabled` 为 `true`。关闭时 `/api/us_market_monitor/*` 全部 404，不创建调度器、不启动线程。
2. 打开网页，导航里第 8 项“美股盯盘”。
3. 点“开始盯盘”（或本机 POST `/api/us_market_monitor/start`）才启动后台线程。
4. 重启网站进程后一律是停止状态，不会自动恢复，需要再点一次。点“停止盯盘”会等待线程与请求子进程回收。

可选的手动连通性验证（有限次数，非时段也能跑，行情会被标成 off_session，这是正常的）：

    .venv/bin/python scripts/validate_us_feed.py --run --symbols AAPL,MSFT --count 3 --interval 60 --timeout 10

脚本写死了上限：最多 5 只、5 轮、总请求 10 次，同一代码至少隔 60 秒，遇到任何失败立即停止。结论固定为“尚未真实验证”，需要你联网运行并与行情软件对照。

## 3. 监控哪些股票
按优先级合并去重：`我的持仓` → `us 自选` → `信号前 N 只`，**总数硬上限 30 只**。

- 持仓：T013 台账目前只支持六位 A 股代码，所以美股第一版为空。
- 自选：读本机 `datasource.load_watchlist('us')`（本机文件或 config 默认列表，不联网）。
- 信号：目前没有美股买卖清单，第一版为空，`top_n` 默认 0。
- 代码规则：1–5 个大写字母，可带 `.X` / `-X` 后缀（如 `BRK-B`）；指数、期货、小写、全角、空白一律丢弃。
- 任一来源出错都降级为空，只写一条日志；每轮开始重新读取，不修改任何来源文件。

## 4. 时段（美东，夏令时自动）
美东周一至周五 09:30–16:00，两端都含，由 `zoneinfo('America/New_York')` 处理夏令时，没有手写偏移。

| 季节 | 北京时间 |
| --- | --- |
| 夏令时（至 2026-11-01） | 21:30–04:00 |
| 冬令时 | 22:30–05:00 |

页面以美东时间为准并附北京时间换算。没有交易日历：节假日（如感恩节）钟表上仍算时段，靠行情时间过旧拦截；半日市同理。行情自带时间晚于 16:00 的标 `after_hours`，不触发提醒。不采集盘前盘后。

## 5. 页面上看什么
- 运行状态、已请求次数/预算、监控只数、已完成轮数、暂停原因。
- 报价表：代码、名称、现价、相对昨收涨跌、采集时间、告警状态、数据质量。
- 告警历史；配置只有两项：采样间隔（60–3600 秒，默认 300）和信号前 N 只（0–30）。其他键一律 400。
- 页面每 10 秒只向本机接口取一次快照；离开页面即停止并清空页面里的报价。
- 页面顶部的“实时分析”三栏（和 A 股版相同的结构，美股规则）：
  - 执行提醒：开盘后 5 分钟内的买入窗口；持仓当日跌幅 > 7%（A 股是 5%）。没有涨跌停提示（LULD 熔断无法从 yfinance 可靠识别，不做识别）。
  - 信号追踪：每条信号的开盘价、现价、相对开盘涨跌%、距当日高/低点。
  - 新机会：开盘后 5 分钟起动量 > 3%、放量（当日累计量 / 20 日均量 > 2 倍）、突破（相对此前当日高/低 > 1%）。成交量单位是股，不乘 100。
  - 流动性过滤：价格 < 5 美元，或 20 日均成交额（近似）< 1000 万美元的股票，只展示，不登记追踪。
  - 因为第一版没有美股持仓和信号，这三栏大部分时候会是空的，主要是新机会在名单上起作用。结果仅参考，未经分钟级回测验证。

## 6. 速率、预算与稳定性
- 默认逐只请求（yfinance 没有批量接口）；同一代码至少 60 秒一次；一次最多 5 只；单次请求超时 10 秒。
- 每次点开始，独立请求预算上限 2500（美股自己的，不动 A 股的 600），**按只计数**，失败也计数；用完暂停并显示 `budget_exhausted`，需手动再点开始。
- 注意：yfinance 内部的时区、cookie、crumb 额外请求不在计数内，首次请求某只代码时实际 HTTP 请求约为计数的 2–4 倍。
- 出错不崩溃：连续 3 次失败或质量异常暂停；失败后下一轮间隔按指数退避（最多 16 倍），一次成功就恢复；429（被限流）单独分类，不重试、不加压。服务层统一重试，provider 自带的重试在这里关闭，避免双重重试加压。
- 单次请求在独立 spawn 子进程里运行，带硬截止（超时 terminate→kill→回收），DNS/TLS 卡住也不会拖死网站。
- 稳定运行的含义是：出错不崩溃、能自愈、能说清楚原因，不是“永不中断”。限流、断网、Mac 睡眠都会中断采集，页面会如实显示暂停原因。
- 过旧阈值 1200 秒、重试间隔等数值是设计文档里的占位值，没有经过真实运行实测。

## 7. 数据与文件
- 状态与告警：`data/us_market_monitor/`；盘中追踪：`data/us_market_monitor_intraday/<美东日期>.jsonl`。
- 目录权限 0700、文件 0600，逐层拒绝符号链接，独占创建，写入后 fsync；存储损坏时失败即关闭，不静默恢复为空配置。
- 报价只在内存里，不进离线整站导出、分享页面、浏览器存储或日志；落盘的只有告警、冷却计数、质量计数和盘中追踪记录。日志只写轮次计数，不写价格或代码。
- 前端全部用 `textContent`；上游返回的名称只当文本显示。
- 两个目录都在 `data/` 下，不进 git。

## 8. 隐私与安全
- 所有接口要求：可信本机（Host 合法、无代理/隧道头、非分享链接）+ 已登录 + `X-Requested-With: dashboard`；写接口还要 Origin 校验。任何一项不满足统一返回同一个 403，不区分原因，探测不到路由。分享页与代理访问一律拒绝。
- 只监听 127.0.0.1；不需要账号密码；不接交易接口；只记录，不下单。
- Polygon.io 免费层只是备选，目前只留了接口；若将来使用，API key 只能走环境变量，不得写进文件。

## 9. 注意事项
- **yfinance 是非官方库，不保证稳定。** 它抓取 Yahoo 的非公开接口，接口变化、被限流或被封都可能导致突然失效，升级 yfinance 版本有时能修复。
- **Yahoo 有速率限制**，宽松但不透明。看到 `rate_limited` 就等一会儿，不要反复点开始；不要调高频率。
- 免费行情可能延迟，具体延迟和限流阈值未核实。现价取自 1 分钟 K 线最后一根，时间用该根起始时间（偏保守）；昨收取前一交易日最后一根收盘，是官方收盘价的近似。
- yfinance 在内部使用 curl_cffi 模拟浏览器的 TLS 指纹和 UA，这是库的实现细节；我们自己的代码不设置 UA/Cookie/Referer，调用期间会临时禁用进程内代理环境变量。
- 盘中价格不是收盘价，不用来重算策略。提醒只是你设置的价格条件，**不构成投资建议**，也不保证送达。
- 已知局限：Mac 睡眠中断采集；采样会漏掉两次采样之间的穿越；无可靠停牌标志；无交易日历；真实联网、连续运行和与行情软件的对照都还没验收。

## 10. 与 T006（A 股盯盘）的关系
两套**独立**：

- 代码：`src/us_market_monitor/` 是新包，没有修改 `src/market_monitor/`。只复用 A 股已验收的鉴权（`Ctx` 四重门禁）、存储安全（`Store`，只换了根目录）和提醒状态机（`alert_step`）。
- 运行：各有各的调度器、开关、预算、数据目录和路由（`/api/market_monitor/*` 与 `/api/us_market_monitor/*`），互不影响；停掉一个不会停另一个。
- 数据：A 股的信号清单（`trade_list_cn.json`）不会混进美股页面。
- 差异：数据源（腾讯 → yfinance）、时段（北京 → 美东）、名单上限（60 → 30）、成交量单位（手 → 股）、无涨跌停与 T+1 提示、持仓下跌阈值（5% → 7%）、预算（600 → 2500）、采样间隔（默认 60 → 300 秒）。

## 11. 回滚
点“停止盯盘”；或把 `personal_mode.json` 的 `enabled` 改为 `false`（路由立即 404；已启动的线程需先停止）。不想用 yfinance 时不装即可。保留 `data/us_market_monitor*/` 供核对，不删除。
