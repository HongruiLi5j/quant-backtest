# 个人模式使用说明

个人模式把网站整理成 **今日 / 信号 / 全市场 / 自选 / 回测** 五项导航，隐藏功能的代码、账户、数据和历史仍保留。默认关闭，不创建配置时使用原完整模式。

## 一条命令开启或关闭

在项目根目录 `quant-backtest` 执行开启命令：

```sh
.venv/bin/python -B -c 'from pathlib import Path; Path("personal_mode.json").write_text("{\"enabled\": true}\n", encoding="utf-8")'
```

关闭并恢复完整模式：

```sh
.venv/bin/python -B -c 'from pathlib import Path; Path("personal_mode.json").write_text("{\"enabled\": false}\n", encoding="utf-8")'
```

这两条命令仅设置根目录开关，不启动网站、不修改业务数据。配置内容会被替换为对应的 `enabled` 值。已部署个人模式代码的服务每次请求读取该文件；执行后刷新所有已打开的网站标签页即可，无须为开关重启服务。首次部署代码仍须按原有方式加载新版本，这里没有更改服务启动方式。

只有 JSON 对象中的 `enabled` 严格为布尔 `true` 才开启。缺文件、不可读、损坏、缺少字段、`false`、数字 `1` 或字符串 `"true"` 都关闭。当前实现不读取 `QB_PERSONAL_MODE` 环境变量，也没有浏览器独立开关。`/api/meta` 的 `personal_mode` 布尔值告知前端当前模式；关闭时为 `false`，其他原有字段保留。

## 开启后保留和整合什么

- 今日：已发布主策略的动作摘要，卖出/减仓优先；盯盘未接入状态；已有会话的个人模拟账户只读摘要；风险提示。基准/组合参考折叠，组合目标与逐股仓位分开显示。
- 信号：保留四类动作、排序筛选、异常、存档日期、CSV 和 XLSX 导出；我的相关、发布后跟踪、信号核对和上线记录集中在一页，按需加载。CSV 沿用当前标签范围，XLSX 保留完整清单范围。
- 全市场、自选、个股下钻和自研回测保留。自选增删仍是明确操作，不会自动订阅盯盘；自研回测原参数、成本和计算规则保留。
- `#/review` 和 `#/track` 进入信号页的对应区块，地址参数保留；关闭个人模式后恢复原独立页面。
- 核对、上线记录与发布后跟踪仍各自标明来源、基准、周期和样本，不能把三者当成同一份成绩。个人模式的历史回放须手动选择。
- 中英文导航、个人页面标签及无数据/错误提示随语言切换。股票名称、外部原因和错误原文保留，新增个人内容以文本节点显示。

## 隐藏了什么，如何恢复

个人模式同时隐藏前端入口并在服务端拒绝下列路径；隐藏接口返回固定 404，不进入原业务处理。关闭开关并刷新后，恢复各功能原有入口与鉴权。

| 隐藏功能 | 服务端范围与例外 | 恢复后的条件 |
|---|---|---|
| 多人会员终端、排行榜、注册登录、密码、重置、模拟下单 | `/member`、`/member/`、`/member.js`、`/api/member/*`；仅可信本机 GET `/api/member/me`、`/api/member/portfolio` 在原主站与会员认证下可读 | 原账户、会话及模拟交易记录保留；需要登录或下单时先关闭个人模式 |
| AI 模拟账户 | `/api/sim`；旧 `#/ai` 转回今日 | 恢复原可直达路由；它原本就没有主导航，不会新增导航 |
| 管理后台 | `/admin`、`/admin/`、`/admin.js`、`/api/admin/*` | 仍需原后台认证和可信本机访问 |
| 分享控制、访客统计、分享口令界面 | `/api/share`、`/api/share_visits`、`/__share_login`、`/share_gate.html`、`/share_gate.js`；不再创建分享轮询 | 保留原口令与认证规则；不会自动启动隧道 |
| Backtrader、RQAlpha、引擎对比 | `/api/eng/*`、`/engines.js`；`#/bt`、`#/rq`、`#/cmp` 转回今日 | 原代码、依赖与任务历史保留；是否可运行仍取决于原环境 |
| 在线代码编辑 | `/api/code/*`；`#/code` 转回今日 | 原文件与版本历史保留 |
| AI 翻译 | `/api/ai/*`、`/ai_translator.js`；`#/translator` 转回今日，首页不加载翻译脚本 | 仍受翻译器自身启用、后端和预算配置控制 |
| 离线整站网页下载 | `/api/offline` 与下载入口 | 恢复原完整页面导出；个人模式不提供整站离线布局，CSV/XLSX 数据导出仍保留 |

路径家族按带斜线的前缀匹配，单独路径精确匹配，原 Host、来源、会话与权限检查保留。个人模式不授予额外权限：分享或代理访问不能使用会员只读例外；未经既有分享口令验证的外部请求被拒绝，不会因口令表单隐藏而放行。

恢复时只需运行上面的关闭命令并刷新所有标签页，无须删除配置、恢复源码或迁移数据。再运行开启命令可重新精简。已加载的旧页面在刷新前可能继续显示旧导航或尝试旧请求，服务端按当前开关处理；HTML 的 ETag/gzip 按最终页面字节区分模式。

## 已知局限与验收边界

- 开关只控制界面和请求入口，不停止此前已运行的隧道、翻译 worker、模拟流程或引擎任务，不改变其独立配置、预算或回收机制。它不是网络隔离开关。
- 配置损坏会恢复完整模式，不能把它当作必须始终生效的访问控制策略。
- 盯盘尚未接入网站，首页只有明确占位，不采集行情、不自动启动监控。T007 离线验证工具包也未接入网站。
- 个人模拟资产只来自已有本机会话的会员账户，不使用 AI 账户兜底。缺会话、会话过期或无数据时显示不可用，不伪造零资产。需要沿用账户时，可关闭模式登录后再开启。
- 个人模式保留数据异常、成本、停牌/涨跌停、样本不足等提示；整理页面没有验证策略有效，也没有改变晋升门槛与冻结期。
- 请求复用仅在当前标签页内；市场、日期、策略或显式刷新改变时失效。缺数据与独立区块失败不会变成真实行情或真实业绩证据。
- 关闭时保留原导航、页面、路由、脚本、分享轮询和自动回放逻辑；W1 已明确增加 `/api/meta.personal_mode: false`，因此响应并非与实施前逐字节相同。
- 离线测试覆盖模式开/关/再开、路由与认证、HTML 缓存、中英切换、请求隔离、导出及原手机卡片。合成 DOM 不执行浏览器排版。W4 无头 Chrome 探针返回 -6，实际 375/768/1440 宽度、明暗/皮肤组合、200% 缩放、键盘焦点外观与无横向溢出仍未完成真实浏览器验收；未验证生产账户、数据或真实下载。

在项目根目录分别运行：

```sh
.venv/bin/python -B tests/test_personal_mode.py
.venv/bin/python -B tests/test_personal_mode_frontend.py
.venv/bin/python -B tests/test_trade_mobile.py
.venv/bin/python -B tests/test_trade_export.py
.venv/bin/python -B tests/test_basic.py
.venv/bin/python -B tests/test_strategies.py
node --check dashboard/app.js
node --check dashboard/i18n.js
git diff --check
```

这些检查使用合成数据或临时目录，不导入真实 `app.py` 初始化。前端动态断言需要本机已有 Node。不要直接在真实工作区全跑其他套件：部分旧测试在导入 `realdata_guard` 时会读取真实数据及外部受保护路径，应另行使用完整隔离的合成环境。W5 实际命令与完整输出见 `handoff/reports/T007_W5.md`。
