# 个人模式方案（T009 W0，尚未实现）

本文件是个人模式的使用与范围摘要。实施细节、源码盘点、接口隐藏矩阵和验收基准见 `handoff/reports/T009_plan.md`（本地交接文件，不随公开仓库发布）。本轮仅写方案，没有修改网站代码或数据。

## 目标与开关

个人模式默认关闭，关闭时保持现有网站行为。开启后精简入口和布局，隐藏的代码、账户、历史及数据全部保留。

拟用进程环境变量 `QB_PERSONAL_MODE`：仅 `1` 开启，缺省、`0` 或其他值关闭。设置后重新启动网站并刷新页面；这不是已上线命令，后续 S1/S5 才实现和核验启动方式。浏览器本地存储不能绕过服务端设置。

恢复时设为 `0`、重启、刷新，原有功能仍受各自认证和独立开关限制。不会自动启动分享隧道、翻译器或盯盘，不迁移账户，不删除或重写旧数据。

## 页面安排

主导航五项：今日、信号、全市场、自选、回测；个股详情由列表下钻。

| 页面 | 区块顺序 |
|---|---|
| 今日 | 今日动作 → 盯盘状态 → 持仓/模拟盘净值 → 风险提示；基准行情/通知放折叠参考 |
| 信号 | 日期/策略 → 买卖及加减仓完整清单 → 我的相关 → 发布后跟踪 → 信号核对 → 上线记录/历史回放 |
| 全市场 | 日期/覆盖风险 → 筛选 → 逐股结果/分页 → 策略总体结果折叠 |
| 自选 | 策略/日期/增删 → 行情和相关动作 → 默认回测/导出 → 口径与异常 |
| 回测 | 研究风险 → 参数/成本/运行 → 结果摘要 → 净值回撤 → 成交收益 → 详细分析 |

“今日买卖”作为信号页主入口；“信号核对”和“信号跟踪”旧链接定位到信号页相应区块。首页只显示动作摘要，不复制整套表格。卖出和减仓优先显示，买入、加仓、异常与导出保留。

三个统计来源仍独立：核对账本看相对全市场的 1/5/10/20 日结果；普通跟踪看相对基准 ETF 的 5/20/60 日结果；发布后清单跟踪使用自己的样本。历史回放必须明确手动选择，不能冒充上线记录；不调整策略公式、晋升门槛或冻结期。

盯盘目前只有离线服务，尚无网页/API 接线。本方案首页显示“尚未接入网站”，不启动采集；真实接线需 T006 另行批准。个人模式不等于盯盘开关，自选也不会自动订阅价格提醒。

首页模拟资产只使用可信本机已有会员会话的只读 me/portfolio，不创建账户或绕过认证。无会话、过期或无数据时明确显示不可用，不显示虚构的零净值，也不拿 AI 账户替代。需要登录或模拟下单时先恢复完整模式；个人模式本身不增加登录和下单能力。

## 隐藏不删

- 多人会员终端、注册登录/密码/重置/下单及排行榜；保留已登录本机会话的资产只读例外。
- 管理后台、分享控制/口令页面/访客统计。
- 在线代码编辑、Backtrader、RQAlpha、三引擎对比。
- AI 账户和 AI 翻译，包括翻译脚本的启动探测。
- 离线整站下载，避免独立导出的页面重新露出完整导航；原 CSV/XLSX 数据导出保留。

不仅隐藏按钮：个人模式下对应页面和 API 拒绝访问，旧书签也不能启动隐藏功能。隐藏分享口令界面不能取消外网口令保护，未满足原有认证的请求应拒绝；已运行的隧道或独立后台任务不会因页面隐藏而自动停止。

关闭个人模式恢复当前网站基线；原来已经无导航的 AI 账户不会被擅自添加到导航，原来未接线的盯盘也不会凭空可用。AI 翻译仍取决于它原有独立开关和后端状态。

## 分阶段落实与验收

| 阶段 | 改动与完成标准 |
|---|---|
| S1 服务端开关 | 纯开关模块、meta、GET/POST 隐藏矩阵、模式隔离缓存；默认 off 同原分派，on 隐藏路径无 handler/任务副作用 |
| S2 导航与隐藏 | 五项导航、旧路由映射、停分享轮询、脚本按模式加载；直接 hash 和动态导航不能重现隐藏功能 |
| S3 页面整合 | 首页四块与信号统一页面；保留清单/导出、统计口径和本机隐私，处理空态/失败/异步切换；盯盘只占位 |
| S4 排版文案 | 375/768/1440 宽度、明暗皮肤、中英、键盘和长文本检查；新增外部文本用 textContent，个人样式不影响 off |
| S5 收尾 | 隔离回归、开关往返、恢复说明、已知限制和实际验收记录 |

主要回归面为今日买卖 DOM/手机卡片/导出、renderBoard 晋升表、AI 脚本顺序、会员和后台权限、缓存及历史回放。现有部分测试的 realdata_guard 会读取真实 data 哈希，不能在本任务直接运行；使用合成夹具与临时副本，绝不导入真实 app 或访问真实凭据。W0 不运行网站，不联网，不执行真实数据测试；实际浏览器布局仍待后续隔离验收。
